# 審查：NFR-003（第 1 輪，2026-11-22）

受審：`docs/sa/nfr/03-SECURITY.md`（Draft，commit 5b0ac4e）。審查者未參與撰寫；本輪未修改 NFR 本文與表頭。

結論：需修正

已決、不列為問題：X-1 收款帳號變更不重驗（使用者 2026-11-22 再確認，維持 baseline CQ-75 / PRD-025 BR-10）；X-2 KYC 可讀者依 baseline §1.2；X-3 簽名網址 300 / 900 秒依 PRD-007 BR-17、PRD-022 BR-18。這三項處理正確。

查證限制：本次執行環境沒有 shell，無法呼叫 gemini CLI、curl 或上網。下列「查證」以官方文件既有知識與 repo 程式碼為準，標「推測」者需實測。

| 33 | 建議 | 表格密度 | SEC-AUTH-3、SEC-WEB-2、SEC-FILE-4 每條塞了 4–6 個情境；NFR 不受 8 AC 限制，但追溯到 TS 時很難一對一 | 子項加上編號（例 `SEC-AUTH-3.4`），讓 SD 和測試可以逐項引用 |

## 查證結果（建議預設值與技術說法）

| 說法 | 判定 | 說明 |
|------|------|------|
| Firebase Hosting 轉發 Cloud Run 只保留 `__session` | 正確 | Firebase 官方「Manage cache behavior」文件明載：搭配 Cloud Functions / Cloud Run 時，其他 cookie 會被移除，只有 `__session` 會轉發，而且會成為 CDN 快取鍵的一部分。NFR 寫「推測」過度保守。連帶影響見 #9 |
| CQ-21 CSP 字串 | 有錯 | `frontend/src/styles/global.css:1` 用 `@import` 載入 `fonts.googleapis.com`，建議值的 `style-src` 缺 `https://fonts.googleapis.com`，也沒有 `font-src https://fonts.gstatic.com`（`default-src 'self'` 會擋），字型會全部失效（列入待回答 R-CQ-1）。GIS 相關來源（`/gsi/client`、`/gsi/style`、`frame-src` / `connect-src` 的 `/gsi/`）和 Google 官方建議一致；`index.html` 沒有 inline script，PWA 是 `injectRegister: false`，`script-src` 不需要 `'unsafe-inline'`，判斷正確 |
| XFF 取右數第 N 個 | 方向對，但 N 不是常數 | 見 #10。兩條入口的跳數不同（推測），需要實測 |
| HSTS 由 Cloud Run 送出 | NFR 本身是對的 | Cloud Run 不會加 HSTS。Spring Security `HstsHeaderWriter` 預設只對 `isSecure()` 的請求輸出。NFR 要求「信任 forwarded 標頭或對所有請求輸出」正確；要注意開 forward-headers 之後 `getRemoteAddr` 會被改寫（#10b）。`.app` 網域本來就在 preload 清單（#25） |
| Node 20 EOL | 正確 | 官方時程是 2026-04-30，已經過期；`deploy.yml:47` 也受影響（#14） |
| bcrypt cost 10 | 合理 | 等於 OWASP 建議的下限，也是 Spring 預設值；但缺 72-byte 上限（#2e） |
| refresh 重用 30 秒寬限 | 寬限本身合理，但實作描述有錯 | 「回傳同一組新 token」和雜湊存放互斥，也會和單一 session 互踢（#8） |
| Spring Boot 4.0 開源支援至 2026-12-31 | 和 Spring 一般支援週期相符（使用者提供） | 距今 39 天，CQ-37 的 90 天緩衝已經不可能用 4.0.x 達成，上線前必須升級到 4.1 或 4.2 |
| Jackson 3 巢狀上限、`1e999999999` | 正確 | Jackson 2.15 起有 `StreamReadConstraints`（Jackson 3 的巢狀上限預設更嚴），但數字只限制長度、不限制指數，所以在做 `BigDecimal` 運算前檢查 `precision` / `scale` 是必要的 |
| `accept-float-as-int=false` 會擋 `100.0` | 正確 | 已經寫在 `application.yml:22` |
